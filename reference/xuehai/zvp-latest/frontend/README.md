# ZVMS 4

> The frontend of ZHZX Volunteer Management System

The v4.2 of ZVMS is brought to you with many new features, which gives you a brand new experience.

ZVMS 4.2 搭载了许多先前版本所想要实现却没有实现的功能。它可以给予你全新的体验。

It checks if you are using XueHai pad with `window.xhBrowserJava`, in order to extend the platform but make you use the pad properly in the school.

我们可以通过 WebView API 自动判断您是使用学海平板访问抑或者普通访问，以便让你合规使用学海平板。
