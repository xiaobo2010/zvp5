# ZVMS 义工平台 · 普通用户端 UI 设计规范

> **版本** v1.0
> **日期** 2026-11-05
> **范围** 普通用户可见页面（首页、义工列表、我的资料、用户主页、登录、关于）
> **状态** 设计阶段，待实现指令
> **约束** 遵守 `docs/前端设计准则.md` 与 `README.md` §7

---

## 1. 设计方向

### 1.1 关键词

| 关键词 | 释义 |
|--------|------|
| **可信** | 这是学校的义工管理平台，不是游戏或概念页；所有元素服务于真实业务 |
| **克制** | 圆角 70% 常规值；动效 ≤450ms；无循环装饰、无弹跳、无伪交互 |
| **清晰** | 信息架构扁平；三级以内；状态反馈即时；空态/加载/错误完备 |
| **温和** | 天蓝主色 + 中性灰；语义色仅用于真实状态；无第二套装饰色 |
| **实用** | 功能优先；删掉玩票性质入口；触控 ≥44px；键盘可达 |

### 1.2 删除元素清单（旧版游戏化/伪交互残留）

- ❌ 任何音游/Phigros/判定线/连击/RKS/分数/等级相关视觉
- ❌ 赛博/霓虹/暗黑 HUD、虚拟币、抽卡、小游戏、彩蛋、玩梗
- ❌ AI 拟人化（聊天机器人头像/对话气泡/拟人表情）
- ❌ 常驻循环动画（粒子、呼吸灯、无限旋转装饰）
- ❌ 无意义的弹跳动效（overshoot > 1.2 的 spring）
- ❌ 装饰性第二主色（保留天蓝 + 语义色，删掉紫/粉/黄装饰）
- ❌ 与普通用户无关的入口（服务器管理、AI 网关管理、实验性功能）
- ❌ 伪交互元素（假进度条、假加载、假通知、占位按钮）

## 2. 信息架构

### 2.1 普通用户导航结构

| 入口 | 路径 | 角色可见 | 说明 |
|------|------|----------|------|
| 首页 | `/user` | 全部 | 问候、身份摘要、时长统计、快捷入口、待办（角色限定） |
| 义工列表 | `/activities/mine` | 全部 | 我的义工（默认）；班级/全校（按角色）；筛选/搜索/分页 |
| 我的 | `/me` | 全部 | 资料卡、设备状态、可编辑字段、保存 |
| 关于 | `/about` | 全部 | 版本、版权、许可证 |
| 登录 | `/user/login` | 未登录 | 品牌区 + 表单；普通/临时密码两种模式 |

**角色相关入口**（已从旧版 `UserNav.vue` 提取，保留业务真实性）：

| 入口 | 路径 | 条件 | 说明 |
|------|------|------|------|
| 添加/修改义工 | `/activity/register` | `admin` 或 `department` | 登记义工成员、修改时长 |
| 平台管理 | `/management` → 分流 | 非纯 `student` | admin/department → `/manage/groups`；secretary → `/group/{class_id}/users` |

### 2.2 导航形态（响应式）

| 断点 | 宽度 | 导航形态 | 顶栏 | 说明 |
|------|------|----------|------|------|
| **桌面** | ≥1280 | 左侧固定导航（72px 图标 + tooltip） | 页面标题 + 用户菜单 + 主题切换 | 常驻液态玻璃侧边栏 |
| **平板横屏** | 960–1279 | 左侧固定导航（72px） | 同上 | 导航项紧凑，文字隐藏 |
| **平板竖屏** | 600–959 | 底部 dock（60px 高） | 页面标题 + 用户头像 | 导航项 4–5 个，主题切换移至用户菜单 |
| **手机** | <600 | 底部 dock（56px 高） | 页面标题 + 用户头像 | 导航项 3–4 个，次要入口收进用户菜单 |

**导航指示器**（药丸高亮）：
- 横屏：左侧导航，垂直排列，指示器为圆角 `--yg-radius-md` 的药丸，天蓝浅底 `--yg-color-primary-soft` + 天蓝图标
- 竖屏：底部 dock，水平排列，指示器同样式，随激活项弹簧滑动（`--yg-ease-spring` 450ms）
- 减少动效时：指示器瞬移，不播放弹簧动画

## 5. 动效系统

### 5.1 命名曲线

| 曲线名 | 值 | 用途 |
|--------|-----|------|
| `--yg-ease-out` | `cubic-bezier(0.25, 0.1, 0.25, 1)` | 默认过渡（颜色、阴影） |
| `--yg-ease-in-out` | `cubic-bezier(0.42, 0, 0.58, 1)` | 对称运动（位移、缩放） |
| `--yg-ease-spring` | `cubic-bezier(0.34, 1.56, 0.64, 1)` | 弹性进出场（药丸指示器、弹窗） |
| **新增** `--yg-ease-list` | `cubic-bezier(0.16, 1, 0.3, 1)` | 列表 stagger、页面淡入 |

**说明**：
- `--yg-ease-list` 为新增曲线，用于列表 stagger 与页面级过渡，提供非线性加速度
- 所有曲线禁止 `linear`（进度条/骨架除外）

### 5.2 动效清单

| 场景 | 触发 | 时长 | 曲线 | 属性 | 减少动态降级 |
|------|------|------|------|------|--------------|
| **页面切换** | 路由变化 | 300ms | `--yg-ease-list` | `opacity` 0→1 | 瞬时切换 |
| **导航指示器** | 激活项变化 | 450ms | `--yg-ease-spring` | `transform` 位移 | 瞬移 |
| **列表 stagger** | 首次加载 | 200ms × N | `--yg-ease-list` | `opacity` + `translateY(-8px)→0` | 同时出现 |
| **数字 count-up** | 数据加载完成 | 800ms | `ease-out` | 数字增量（JS 驱动） | 直接显示终值 |
| **卡片 hover** | 鼠标悬停 | 200ms | `--yg-ease-out` | `translateY(-2px)` + `box-shadow` | 瞬时完成 |
| **骨架 shimmer** | 加载中 | 200ms | `ease-in-out` | 渐变位移（单次，非循环） | 静态灰块 |
| **主题切换** | 点击主题按钮 | 450ms | `linear` | 图标旋转 360° + View Transitions | 瞬时切换 |
| **弹窗进入** | 打开弹窗 | 300ms | `--yg-ease-spring` | `scale(0.96)→1` + `opacity` | 瞬时显示 |
| **弹窗退出** | 关闭弹窗 | 200ms | `--yg-ease-out` | `scale(1)→0.96` + `opacity` | 瞬时隐藏 |
| **表单 focus** | 输入框聚焦 | 100ms | `--yg-ease-out` | `border-color` + `box-shadow` | 瞬时完成 |
| **保存成功** | 提交成功 | 200ms | `--yg-ease-out` | 按钮背景色变绿，1s 后恢复 | 不变色 |

**说明**：
- 所有动效单次 ≤450ms（药丸指示器为上限）
- 禁止常驻循环动画（骨架 shimmer 为单次，加载完即停止）
- 禁止无意义弹跳（spring 曲线仅用于药丸指示器与弹窗，overshoot 控制在 1.56）
- 减少动效时（`prefers-reduced-motion: reduce`）：所有过渡 ≤10ms（base.css 全局降级已内置）

### 5.3 编排示例（列表 stagger）

```css
/* 活动列表首次加载，逐行淡入上移 */
.yg-list__item {
  opacity: 0;
  transform: translateY(-8px);
  animation: fade-in-up 200ms var(--yg-ease-list) forwards;
}

.yg-list__item:nth-child(1) { animation-delay: 0ms; }
.yg-list__item:nth-child(2) { animation-delay: 50ms; }
.yg-list__item:nth-child(3) { animation-delay: 100ms; }
/* ... 最多 8 项，总时长 350ms */

@keyframes fade-in-up {
  to {
    opacity: 1;
    transform: translateY(0);
  }
}

@media (prefers-reduced-motion: reduce) {
  .yg-list__item {
    animation: none;
    opacity: 1;
    transform: none;
  }
}
```

2. **时长计算**：三类义工时长折算、达标判定 → 保持 `ZUserTimeJudge` 组件
3. **活动状态**：进行中/已结束/待审核 → 保持后端返回的状态枚举
4. **角色权限**：admin/department/secretary 权限判定 → 保持 `user.position` 逻辑
5. **表单校验**：邮箱/手机号正则、必填项 → 保持现有校验规则

### B. 可优化的体验细节

1. **列表 stagger**：首次加载时逐行淡入上移（200ms × N，最多 8 项）
2. **数字 count-up**：时长统计数字从 0 增长到目标值（800ms）
3. **保存成功反馈**：按钮短暂变绿（1s）+ 全局消息（2s 自动消失）
4. **骨架屏**：加载超过 300ms 显示骨架，微光扫过（单次 200ms）
5. **药丸指示器**：导航切换时弹簧滑动（450ms spring），减少动效时瞬移

### C. 性能优化建议

1. **懒加载**：v2 页面使用 `() => import()` 动态导入，避免打包进主 chunk
2. **图片优化**：Logo/头像使用 WebP 格式，提供 1x/2x 分辨率
3. **骨架屏缓存**：首次渲染后缓存骨架屏 HTML，下次访问瞬时显示
4. **列表虚拟滚动**：活动列表 >100 项时使用虚拟滚动（`vue-virtual-scroller`）
5. **药丸指示器防抖**：高频切换时合并动画请求（WAAPI `cancel()` 旧动画）

## 总结：五条最关键的决策

1. **删掉所有游戏化/伪交互元素**：这是义工管理平台，不是音游或概念页，所有元素服务于真实业务。
2. **弹窗/抽屉/下拉全部不透明**：遵守准则第 6 章铁律，所有弹出面板使用实色 `--yg-bg-surface-raised`，只有遮罩 `.yg-mask` 允许半透明。
3. **动效克制 ≤450ms**：药丸指示器为上限，禁止常驻循环、无意义弹跳；减少动效时全局降级 ≤10ms。
4. **导航响应式分离**：桌面左侧固定导航（72px 液态玻璃）→ 平板竖屏/手机底部 dock（60px/56px），药丸指示器跟随布局切换方向。
5. **只用现有令牌系统**：所有样式引用 `--yg-*` 变量，复用现有组件类（`.yg-card` / `.yg-btn` / `.yg-form` 等），新增类名最少化（只布局容器与页面级组件）。
