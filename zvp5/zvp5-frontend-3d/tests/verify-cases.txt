Expected behavior analysis:

Portrait (screenAngle=0):
- β增加（设备顶部远离用户）→ 视觉上前后倾 → pitch增加 ✓
- γ增加（设备向左倾斜）→ 视觉上左右倾 → roll增加 ✓

Landscape-left (screenAngle=90, 设备逆时针旋转90°):
- 此时设备的物理轴和视觉轴的关系：
  * device-x (原本指向右) 现在视觉上指向上
  * device-y (原本指向上) 现在视觉上指向右
- β增加 (绕device-x，即visual-up轴旋转) → 视觉上左右倾 → roll!
- γ增加 (绕device-y，即visual-right轴旋转) → 视觉上前后倾 → pitch!

所以问题是：在横屏模式下，β和γ的角色互换了！

正确的映射应该是：
Portrait:  visualPitch = f(β), visualRoll = f(γ)
Landscape: visualPitch = f(γ), visualRoll = f(β)

更准确地说，应该根据screenAngle进行线性组合。
