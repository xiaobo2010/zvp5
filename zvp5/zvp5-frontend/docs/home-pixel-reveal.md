# 首页作品揭示测试

## 本地试跑（不需要后端）

当前工作区的依赖已安装。在 PowerShell 中可直接运行本地 Vite，避免全局包管理器版本差异触发重新安装：

```powershell
cd D:/zvp5/zvp5/zvp5-frontend
node scripts/sync-design-css.mjs
node node_modules/vite/bin/vite.js --config vite.home-preview.config.ts --port 5173 --strictPort --open /home-preview.html
```

打开 http://localhost:5173/home-preview.html 。端口占用会明确报错，不会悄悄切换端口。页面底部的「调节进度」可切换演示账号、三类原始时长、加载/失败状态和深浅色主题。测试值只留在页面内存，刷新会恢复演示默认值。此入口不会加载登录、真实 API、维护检测或设备校验。

项目固定使用 pnpm 10.34.5。使用该版本时，也可执行 pnpm dev:home；全新检出先执行 pnpm install --frozen-lockfile。本机工具环境的全局 pnpm 11 会尝试重新安装依赖，故上方给出不经过包管理器的启动方式。

建议以 480 × 929 CSS 像素模拟约 123:238 的有效显示比例，也可查看 360 × 697、768 × 1486。毫米与 CSS 像素不存在固定换算，这里保留的是屏幕宽高比。

## 正式首页与构图

正常启动仍使用 pnpm dev，后端按仓库原有流程运行；登录后访问 /user。首页复用与预览相同的展示组件。账号资料、活动入口、时长明细和管理人员待办仍可使用。

测试版采用一幅完整作品作为主体，左、中、右三等份对应校内义工、校外义工、社会实践。保留作品原始比例，不拉伸或裁掉构图；最大高度按视口限制。横幅与竖幅均能适配。

原有目标分别为 25、15、18 小时。互补折算沿用既有规则：校外超过 15 小时的部分按 1/2 四舍五入计入校内，校内超过 25 小时的部分按 1/3 四舍五入计入校外。累计时长只加原始值。数字可显示超过 100%，图片揭示上限为 100%。

每个区域在固定逻辑画布上揭示 floor(完成比例 × 区域像素数) 个像素。使用稳定的随机网格顺序；增加进度只追加揭示，已有像素保持。最后一个网格按整行和单行余数切分，使比例误差小于一个逻辑像素。0% 不绘制任何作品像素，100% 完整还原作品，不通过透明度或模糊底图显示隐藏内容。

## 固定分配和素材

图片编号和路径种子由稳定账号 ID（user._id）确定，刷新、重新登录或切换设备不会重新抽图。三个演示账号也使用同一算法。没有账号 ID 时不分配。

此测试版的素材清单、顺序、分配盐值和网格尺寸为 v1 固定约定。直接增删或重排素材清单会改变既有账号分配；后续扩图应先引入服务端持久分配或带版本的迁移方案。素材文件位于 src/assets/home-artworks，授权、原始地址和处理记录见该目录 README。运行时使用本地资源，不依赖外部图片服务。

首次时长读取完成前不把未知值显示成 0。刷新失败保留本次会话已知数据并显示提示；账号变化立即清空旧进度，迟到的旧账号响应不能覆盖当前用户。

## 验证和构建

```powershell
pnpm exec vitest run --maxWorkers=4
pnpm type-check
pnpm lint
$env:VITE_API_BASE = '/api'
pnpm build
```

生产打包沿用 index.html 单入口，不打包独立预览页面。规范样式源位于仓库根目录 前端约定/css/home-artwork.css；启动和构建会同步至前端，勿直接修改生成的副本。

2026-11-15 验证：102 个测试文件、1150 项测试全部通过；类型检查和生产构建通过。ESLint 无错误，保留原有 ZMarkdown.vue 的一条 v-html 警告。限制测试并发可避免本机全量运行时原有路由加载测试触发 5 秒超时。

浏览器已检查 360、480、768 三种宽度与深浅色：无横向溢出、三栏与图像边界对齐；实测画布揭示面积与比例一致，100% 与完整原图绘制一致，0% 完全遮蔽。账号切换、刷新和独立浏览器会话保持相同作品与揭示路径；首次读取失败、刷新失败和图片重试均已验证。独立预览未发起 API 请求。正式接口接线由组件测试覆盖，本轮未使用线上账户联调。
