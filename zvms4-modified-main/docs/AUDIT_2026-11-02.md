## 4. 建议清单(需要产品/架构拍板,本次不动)

**安全/架构**
1. 长效 token 10 天 + localStorage、无 refresh/设备绑定(`util/cert.py:246`):任一 XSS 即 10 天全站权限。建议短 access + refresh 或 HttpOnly cookie。
2. 缓存失效先于事务 commit 的 30s 陈旧窗(`db/cached_repos.py:188` vs `users.py:1317`):封禁/角色变更后已封用户最多 30s 仍可通过认证。建议 after_commit 钩子或 epoch 化 auth 缓存键。
3. 语句级无超时 + 池满时 `pool_timeout` 阻塞事件循环(`db/oracle/engine.py:33-69`):一条慢 SQL 可占死 16 条连接并冻结全站 5s。建议 oracledb `call_timeout`(先验证 thin 模式支持度)+ 池等待改短超时快 503。
4. 附件签名链接不绑定用户、1h 内可转发(`util/attachment.py:122`):建议 TTL 降分钟级或纳入接收者 oid。
5. `ssh_bridge` 缺省 fail-open(默认 root@127.0.0.1 + 默认密钥路径,`services/ssh_bridge.py:44`):建议缺显式配置即拒绝启用。
6. `regex=true` 时用户正则直进 `REGEXP_LIKE`(灾难性回溯 DoS 面,`activities_v2_router.py:170`):建议长度/复杂度上限。
7. 附件上传日配额是进程内计数(`util/attachment.py:306`):多进程/重启即失效,建议 Redis 化。
8. 文件 download/preview 与维护模式开关建议加密码再认证(与 chmod 等兄弟操作对齐;当前仅 admin 闸)。
9. 单 worker 是全局前提(run_queue/调度器/进程内锁)但无启动防护:建议 `--workers>1` 直接拒绝启动。

**数据层(收益明确,涉 schema 或大面积重构,建议单独排期)**
10. 只读仓储每次自建 session 多付一次 ROLLBACK 往返(`db/oracle/session.py:85`)。
11. `push_result` 对 result CLOB 读-改-写,导出过程 O(N²)(`tasks.py:305`):建议行表化。
12. `COALESCE(task_end, task_start)` 谓词无法走索引(`exports_router.py:57`):建议函数索引。
13. `claim_due` 逐条 CAS/commit、配额审批三步跨事务(AI 子系统,低频)。

**产品语义**
14. 活动成员名单对任意登录用户开放,v3 内嵌完整 profile(学号/姓名/性别/班级,`activities_v3_router.py:98-145`):学生隐私敏感,建议按同班/管理者收口或 v3 只回 `member_name+duration`。
15. `exports/users` 入口对 department/secretary 可见但后端只认 admin,必 403(`ZGroupUserList.vue:261`):前端隐藏或后端放宽,二选一。
16. socket.io 端点前端从不连接(全仓零 import)但后端维护着完整挂载:考虑整体下线。

**前端质量包**
17. 双 toast(拦截器+页面各一条):约定 `__silent` 标记。
18. `cancelInFlightRequests` 死代码 + 重试请求脱离取消体系。
19. 无鉴权路由守卫,先渲染再被 401 弹回(闪烁+无意义请求)。
20. 缓存准入判断在 Authorization 注入之前(「不缓存鉴权响应」靠巧合成立)。
21. 构建侧 gzip(现流水线手工 `gzip -9k`):可评估 vite-plugin-compression(需先审计依赖)。
22. 死依赖清理(socket.io-client、parseJwt、signLink;`dependencies` 混入 oxlint/pnpm/monaco;xlsx 走 CDN tarball 无 SRI)。
