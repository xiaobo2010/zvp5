# 义工平台前端设计准则

> 版本 v1.0 · 2026-10-24
> 适用范围：义工平台全部前端页面、组件与后续迭代
> 读者：前端智能体、前端开发者、UI 评审者
>
> **本文档是义工平台前端视觉与交互的唯一事实来源。任何智能体在编写前端代码前，
> 必须先完整阅读本准则；样式实现必须引用 `css/design-tokens.css` 中的 `--yg-*` 变量，
> 禁止自由发挥。**

---

## 0. 决策速览（TL;DR）

| 决策点 | 规定 |
| --- | --- |
| 整体风格 | 瑞士国际主义（网格、留白、功能优先）× 苹果质感（连续曲率、柔和阴影、流畅动效），扁平化，界面简洁克制 |
| 主色 | 天蓝 `--yg-sky-500 #0EA5E9`，仅用于主操作、选中态、链接、品牌元素 |
| 高危/破坏性操作 | 红色 `--yg-red-500 #FF3B30`，且必须二次确认（见第 5 章）；红色不得用于装饰或普通提示 |
| 圆角 | Apple G2 连续曲率：`border-radius` + `corner-shape: squircle` 渐进增强（Chromium 139+），其余浏览器回退普通圆角（见 2.4） |
| 半透明 | 默认不使用。仅三类允许：背景装饰层毛玻璃、侧边栏液态玻璃、弹出层遮罩（见 2.6） |
| 弹出页面 | **一律不允许半透明**，面板背景强制实色；禁止对弹出面板使用 `backdrop-filter`（见第 6 章） |
| 层次感 | 用阴影与留白表达，**禁止**立体按钮、渐变浮雕、3D 质感 |
| 按钮 | 扁平实色或描边；圆角 md；主按钮天蓝，危险按钮红 |
| 侧边栏 | 允许液态玻璃（`--yg-liquid-glass` 配方，见 2.6） |
| 类名前缀 | `yg-`，BEM 风格；状态类 `.is-*` |
| 样式约束 | 只用 `--yg-*` 变量；禁止 `!important`（仅 `prefers-reduced-motion` 降级为特例）；禁止魔法数值 |

## 1. 设计哲学

### 1.1 两种风格如何融合

| 维度 | 取自瑞士风格 | 取自苹果风格 |
| --- | --- | --- |
| 布局 | 严格栅格、8px 网格、对齐理性、功能分区清晰 | 大圆角卡片、充足留白、内容居中于视觉重心 |
| 排版 | 无衬线、层级靠字号与字重而非装饰、数字等宽 | 苹方/SF 系统字体栈、标题 Semibold、行高 1.25–1.5 |
| 色彩 | 单一主色天蓝 + 中性灰阶，语义色克制 | 品牌蓝的柔和浅底（`*-soft`）、深色模式完整适配 |
| 装饰 | 几乎无装饰元素，一切为功能服务 | 连续曲率圆角、柔和双层阴影、细腻动效 |
| 质感 | 大面积实色、清晰的 1px 边框 | 液态玻璃侧边栏、毛玻璃背景、高光内边 |

### 1.2 六条设计原则

1. **清晰优先**：每个界面回答三个问题——"我在哪、能做什么、做了什么"。
2. **克制**：默认不加修饰；每增加一个颜色、一条边框、一层阴影都要有理由。
3. **一致**：同类元素必须复用同一组件与令牌，同一语义必须用同一颜色。
4. **层次**：层次只靠留白、字号、字重、阴影四样工具表达，不靠立体质感。
5. **即时反馈**：一切可交互元素必须有 hover / active / focus-visible / disabled 四态；
   异步操作必须给出 loading / success / error 反馈。
6. **可访问**：文本对比度 ≥ 4.5:1，UI 组件对比度 ≥ 3:1；完整键盘可达；尊重减少动效偏好。

### 1.3 设计红线（绝对禁止）

- ❌ 弹出页面（弹窗/抽屉/气泡/下拉/消息等）使用半透明背景或毛玻璃。
- ❌ 立体按钮：渐变高光浮雕、3D 斜面、拟物材质、厚重内阴影。
- ❌ 大面积滥用半透明叠加层。
- ❌ 在非高危场景使用红色（红色 = 危险，不用于促销、装饰、普通图标）。
- ❌ 超出天蓝 + 中性灰 + 绿/橙/红语义色的第二套装饰色。
- ❌ 圆角随意取值、随意混用（必须取自 2.4 令牌）。
- ❌ 阴影过硬（纯黑、大扩散、无层级依据）。
- ❌ 动效喧宾夺主（> 450ms 的常驻动画、无意义的弹跳）。
- ❌ 硬编码色值、魔法数值、`!important`。

## 2. 设计令牌

> 令牌定义见 `css/design-tokens.css`，以下为使用规范。组件样式**只允许引用语义令牌**
> （`--yg-color-*`、`--yg-text-*`、`--yg-bg-*`、`--yg-border-*`），
> 色阶（`--yg-sky-500` 等）仅在设计令牌文件内被语义令牌引用。

### 2.1 色彩系统

#### 主色 · 天蓝

| 变量 | 值 | 用途 |
| --- | --- | --- |
| `--yg-color-primary` | `#0EA5E9` | 主按钮、选中态、滑块填充、进度条、焦点相关 |
| `--yg-color-primary-hover` | `#0284C7` | 主按钮悬停（深色模式为 `#38BDF8`） |
| `--yg-color-primary-active` | `#0369A1` | 主按钮按下 |
| `--yg-color-primary-soft` | `#F0F9FF` | 主色浅底：选中项底色、信息类提示底 |
| `--yg-color-primary-strong` | `#0369A1` | **实底主按钮底色（承白字 5.93:1）**；品牌天蓝压白字仅 2.6:1，只能做图标/边框/选中态 |
| `--yg-color-primary-strong-hover` | `#075985` | 实底主按钮悬停（白字 7.56:1） |
| `--yg-color-primary-strong-active` | `#0C4A6E` | 实底主按钮按下（白字 9.46:1） |

#### 中性灰（Apple 灰阶）

| 变量 | 值 | 用途 |
| --- | --- | --- |
| `--yg-bg-page` | `#F5F5F7` | 页面底色（深色 `#0D0D0F`） |
| `--yg-bg-surface` | `#FFFFFF` | 卡片、面板（深色 `#1C1C1E`） |
| `--yg-bg-surface-raised` | `#FFFFFF` | 弹出层面板，**强制不透明**（深色 `#2C2C2E`） |
| `--yg-bg-surface-sunken` | `#F2F2F7` | 凹陷区：表头、输入槽、进度轨道 |
| `--yg-border-default` | `#E5E5EA` | 常规 1px 边框 |
| `--yg-text-primary / secondary / tertiary` | `#1C1C1E / #48484A / #8E8E93` | 文字三级 |
| `--yg-text-disabled` | `#C7C7CC` | 禁用文字（仅占位符级，**不得**用于按钮/输入框等控件正文） |
| `--yg-text-disabled-control` | `#8A8A8F` | **禁用控件正文**（浅灰底 3.08:1，满足 3:1 下限） |
| `--yg-text-link / -hover / -active` | `#0369A1 / #075985 / #0C4A6E` | 主色文字与链接：白底 5.93 / 7.56 / 9.46:1，悬停按下只许往深走 |
| `--yg-text-danger-hover` | `#A50011` | 危险文字悬停（白底 8.05:1） |
| `--yg-focus-ring-color` | `#0369A1` | 焦点环外圈（白底 5.93:1；深色为 `#38BDF8` 7.94:1） |
| `--yg-focus-ring-inner` | `#FFFFFF` | 焦点环内圈分隔色，与元素底色拉开对比 |
| `--yg-focus-ring` | 双层 `0 0 0 2px 内圈 + 0 0 0 4px 外圈` | 键盘焦点环（替代原先单层 3px 光环） |

#### 语义色

| 语义 | 主色 | 文字色 | 浅底 |
| --- | --- | --- | --- |
| 成功 | `--yg-color-success #34C759` | `--yg-text-success #1E7E34` | `--yg-color-success-soft` |
| 警告 | `--yg-color-warning #FF9500` | `--yg-text-warning #C93400` | `--yg-color-warning-soft` |
| **危险** | `--yg-color-danger #FF3B30` | `--yg-text-danger #D70015` | `--yg-color-danger-soft` |
| 信息 | `--yg-color-info #0EA5E9` | — | `--yg-color-info-soft` |

**实底语义色（承白字，≥4.5:1）**：`--yg-color-danger-strong #D70015` /
`-hover #A50011` / `-active #7A000C`（白字 5.39 / 8.05 / 11.46:1）；
`--yg-color-success-strong #1E7E34` / `#16662A` / `#0F4A1E`（白字 5.20 / 7.08 / 9.30:1）；
`--yg-color-warning-strong #C93400` / `#A32A00` / `#7F2100`（白字 5.32 / 7.30 / 9.20:1）。
与 primary 一样，只有**实心按钮底色**可以引用；`--yg-color-danger` / `success` / `warning`
继续用于图标、边框与浅底。

**使用规则**

- 天蓝 = 平台主色，可做品牌装饰（Logo、头部点缀、图表第一色）。
- 绿色 = 成功；橙色 = 警告；**红色 = 危险，只准用于破坏性操作及其警示**，
  例如删除、清空、注销、退款。普通"错误提示"可用红色文字，但普通图标、标签
  不得随意上红。
- 一个界面内主色最多占视觉面积 15%，语义色合计不超过 10%，其余交给中性灰。

#### 暗色模式

- 通过 `<html data-theme="dark">` 手动切换；不设置时跟随 `prefers-color-scheme`。
- 暗色下弹出面板 `--yg-bg-surface-raised: #2C2C2E`，依然**不透明**。
- 暗色下阴影改用更深、更实的黑色投影（令牌内已定义）。

### 2.2 字体与排版

```css
font-family: -apple-system, BlinkMacSystemFont, "SF Pro Text", "SF Pro SC",
  "PingFang SC", "HarmonyOS Sans SC", "Segoe UI", "Microsoft YaHei",
  "Helvetica Neue", Arial, sans-serif;
```

| 层级 | 字号 | 字重 | 行高 | 用途 |
| --- | --- | --- | --- | --- |
| 页面标题 | 24px | 600 | 1.25 | `.yg-page-header__title` |
| 区块标题 | 20px | 600 | 1.25 | h2 / 卡片大标题 |
| 小标题 | 18px | 600 | 1.35 | h3 / 弹窗标题 |
| 强调正文 | 16px | 500 | 1.5 | 说明文字、按钮文字 |
| 正文 | 14px | 400 | 1.5 | 默认正文 |
| 辅助 | 13px | 400 | 1.5 | 表单标签、表格 |
| 弱化 | 12px | 400 | 1.5 | 角标、时间戳、辅助说明 |

- 数字与日期使用等宽数字 `.yg-text-num`（`font-variant-numeric: tabular-nums`）。
- 标题不加粗装饰、不用颜色渐变；强调用字重与留白。

### 2.3 间距

- 一律 4px 网格，取值：4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48 / 64。
- 页面内容区内边距 24px；卡片内边距 16–24px；组件间纵向节奏 16px 起步。
- 表单行间距 20–24px；分组之间 32px。

### 2.4 圆角 · Apple G2 连续曲率

**原理**：Apple 的 G2 曲率（二阶几何连续）指圆角从直线到弧线过渡时曲率连续变化，
即"超椭圆/方圆形（squircle）"，肉眼效果是圆角更圆润、转角不生硬。

**实现（渐进增强）**：

```css
/* 1) 所有组件先写普通圆角（全浏览器可用） */
.yg-card { border-radius: var(--yg-radius-lg); }

/* 2) 支持 corner-shape 的浏览器（Chromium 139+）自动升级为 G2 连续曲率；
      border-radius 负责尺寸，corner-shape 负责曲线形状 */
@supports (corner-shape: squircle) {
  .yg-card { corner-shape: squircle; } /* 等价 superellipse(2)，即 iOS 观感 */
}
```

- 图片裁切等 `border-radius` 无法覆盖的场景，使用 `.yg-g2-mask`（内置 SVG 遮罩，近似 G2）。
- 圆（头像、圆点、加载环）保持 `border-radius: 50%`，**不要**套用 corner-shape。

**圆角取值表（必须取自下表，不得自定义）**：

| 令牌 | 值 | 适用 |
| --- | --- | --- |
| `--yg-radius-xs` | 6px | 小标签、徽章、迷你控件 |
| `--yg-radius-sm` | 8px | 复选/单选内块、开关内块、迷你按钮 |
| `--yg-radius-md` | 12px | **按钮、输入框、下拉、标签页、菜单项** |
| `--yg-radius-lg` | 16px | **卡片、气泡、下拉菜单容器、头像(方形)** |
| `--yg-radius-xl` | 20px | **弹窗、抽屉、通知卡片** |
| `--yg-radius-2xl` | 24px | 大卡片、登录卡、Hero 图 |
| `--yg-radius-pill` | 999px | 胶囊：开关、徽标、分段控件 |

### 2.5 阴影与层次（扁平化的层次来源）

**层次哲学**：扁平设计禁用立体质感，层次感全部由阴影 + 留白表达。
阴影必须柔和、双层（近小远大）、颜色偏灰蓝黑。

| 令牌 | 使用场景 |
| --- | --- |
| `--yg-shadow-xs` | 输入框内块、细微区分 |
| `--yg-shadow-sm` | 主按钮常态、小卡片 |
| `--yg-shadow-md` | 悬停抬升、下拉菜单、气泡卡 |
| `--yg-shadow-lg` | 弹窗、抽屉 |
| `--yg-shadow-xl` | 最高层级弹层、Hero 卡片 |
| `--yg-shadow-inset` | 按压态、凹陷槽 |
| `--yg-focus-ring` | 键盘焦点环（双层：内圈 2px 分隔 + 外圈 2px 强色） |

**z-index 层级**：dropdown 1000 → sticky 1020 → mask 1040 → popup 1050 →
toast 1060 → tooltip 1070（使用 `--yg-z-*` 令牌）。

### 2.6 透明度与毛玻璃（重点规范）

**总原则：半透明效果不应大量使用。** 全站只有三类半透明，见下表：

| 对象 | 是否允许 | 实现 |
| --- | --- | --- |
| 背景装饰层 / 横幅 / Hero | ✅ 允许 | `.yg-frost`：白色渐变 + `backdrop-filter: blur(20px) saturate(160%)`，可叠加 `.yg-frost--fade` 渐隐 |
| 侧边栏（液态玻璃） | ✅ 允许 | `.yg-liquid-glass` 配方，见下 |
| 弹出层遮罩 | ✅ 允许 | `.yg-mask`：`rgba(0,0,0,0.35)` + `blur(6px)` |
| **弹出页面面板（弹窗/抽屉/气泡/下拉/消息/通知）** | ❌ **禁止** | 必须 `background: var(--yg-bg-surface-raised)` 实色，禁止 `backdrop-filter`、禁止半透明背景 |
| 卡片、表格、表单等普通内容面板 | ❌ 默认禁止 | 默认实色 `--yg-bg-surface`；确需玻璃效果须评审 |
| 输入框、按钮等控件 | ❌ 禁止 | 实色 |

**液态玻璃配方（浅色）**：

```css
.yg-liquid-glass {
  background: linear-gradient(160deg, rgba(255,255,255,0.82), rgba(255,255,255,0.60));
  backdrop-filter: blur(28px) saturate(180%);
  border-right: 1px solid rgba(255,255,255,0.55);
  box-shadow: inset 0 1px 0 rgba(255,255,255,0.65), 0 8px 32px rgba(28,28,30,0.08);
}
```

- 侧边栏玻璃感依赖背后内容的色彩，页面背景层可放置天蓝低饱和光斑（见 3.1）。
- 深色模式配方见 `base.css`（深灰渐变 + 白高光）。
- 液态玻璃**只**用于侧边栏等常驻面板，不得移植到弹出面板。

### 2.7 动效

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--yg-dur-fast` | 100ms | hover、按压反馈 |
| `--yg-dur-base` | 200ms | 常规过渡（颜色、阴影） |
| `--yg-dur-slow` | 300ms | 弹层进出场 |
| `--yg-ease-out` | `cubic-bezier(0.25,0.1,0.25,1)` | 默认 |
| `--yg-ease-spring` | `cubic-bezier(0.34,1.56,0.64,1)` | 弹窗缩放、徽标弹出 |

- 弹窗：遮罩淡入 + 面板 `scale(0.96)→1` 弹簧，200–300ms。
- 抽屉：位移 240–300ms + 遮罩淡入。
- 必须支持 `prefers-reduced-motion: reduce` 全局降级（base.css 已内置）。

### 2.8 布局、栅格与断点

| 断点 | 宽度 | 行为 |
| --- | --- | --- |
| 小屏 | < 640px | 栅格全部 1 列；侧边栏转为抽屉 |
| 中屏 | ≥ 640px | 栅格 2–4 列 |
| 桌面 | ≥ 1024px | 12 栅格完整；侧边栏常驻 |
| 大屏 | ≥ 1280px | 内容区最大 1280px 居中 |

- 12 栅格（`.yg-row` / `.yg-col-1…12`），列距 16px，行距 16–24px。
- 内容容器 `.yg-container`：max-width 1280px，两侧 24px。
- 页面骨架：侧边栏 260px（收起 72px）+ 顶栏 56px + 内容区，见 3.1。

## 3. 全局规范

### 3.1 页面骨架

```
┌──────────┬──────────────────────────────────────┐
│ 侧边栏    │ 顶栏（56px，粘性）                      │
│ 260px    ├──────────────────────────────────────┤
│ 液态玻璃  │ 内容区（padding 24px）                  │
│          │  · 页面头部（标题/副标题/操作区）          │
│          │  · 页面内容                             │
└──────────┴──────────────────────────────────────┘
```

- 侧边栏 `.yg-sidebar` + `.yg-liquid-glass`：品牌区（Logo + 名称）、菜单、底部用户区。
- 页面背景如需玻璃感：在内容层之下放 1–2 个天蓝低饱和大光斑
  （`filter: blur(80px)` + 低透明度 + 天蓝色，位置固定不干扰内容）。
- 每个页面必须有 `.yg-page-header`：标题、副标题（可选）、右侧操作区（主操作按钮）。

### 3.2 导航规范

- 当前页面在侧边栏菜单中必须高亮（`.is-active`）。
- 面包屑用于三级以上页面；一级页面（仪表盘）可省略。
- 顶栏左侧：折叠按钮 + 面包屑或页面名；右侧：搜索、通知、用户头像。

### 3.3 图标

- 一律线性图标，描边 1.5px，圆头线帽，尺寸 16 / 20 / 24px（与文字基线对齐）。
- 语义映射：默认中性灰 `--yg-text-tertiary`；选中/主操作天蓝；**危险操作红**；
  成功绿；警告橙。
- 图标按钮使用 `.yg-icon-btn`，禁用彩色背景图标（除危险操作）。

### 3.4 文案

- 语气：简洁、肯定、动词开头（"创建活动" 而非 "活动的创建"）。
- 按钮文案 ≤ 6 字，动宾结构；确认弹窗标题用完整动词句（"删除该活动？"）。
- 危险操作文案必须说明后果与不可恢复性（见第 5 章）。

### 3.5 表单规范

- 标签在控件上方，必填项星号用 `--yg-text-danger`。
- 校验反馈：控件红边框 + 下方红字错误信息；成功后错误信息消失，不做绿框（避免喧宾）。
- 主操作按钮永远只有一个（天蓝）；次级用 secondary/ghost；危险操作用 danger。

### 3.6 反馈规范

- **加载**：> 300ms 的操作显示 loading（按钮内 spinner 或区域遮罩）；
  > 1s 建议骨架屏。
- **空状态**：`.yg-empty`（图标 + 标题 + 说明 + 行动按钮），禁止空白区域。
- **结果页**：表单提交、支付、报名等关键流程终点使用 `.yg-result`。
- **错误**：全局消息 `.yg-message--danger`；局部错误用表单错误信息或 `.yg-alert--danger`。

### 3.7 响应式

- 所有栅格 ≤ 768px 单列；侧边栏 ≤ 1024px 转抽屉（带 `.yg-mask`）。
- 表格 ≤ 768px 使用横向滚动容器（`.yg-table__wrapper`），不做列折叠。
- 触控目标最小 44×44px（移动端）。

### 3.8 无障碍

- 对比度：正文 ≥ 4.5:1；大字号/UI 组件 ≥ 3:1。
- 所有交互元素必须支持键盘聚焦且显示 `--yg-focus-ring` 焦点环。
- 图标按钮必须有 `aria-label`；弹窗必须有 `role="dialog"` + `aria-modal="true"`；
  开关/复选用原生 input 驱动，保证语义正确。

  方向 `--left/--right/--top/--bottom`，位移滑入 300ms；结构同 modal 三段式。

#### 4.5.9 加载 `.yg-spinner` / `.yg-loading`

- `.yg-spinner` 圆环旋转（天蓝），尺寸 sm 16 / md 24 / lg 32，`--inverse` 白。
- `.yg-loading` 区域遮罩：白底（不透明）+ spinner + 文案，`--fullscreen` 全屏。

#### 4.5.10 结果页 `.yg-result`

- `__icon`（语义色软底圆形 + 线性图标：success 绿 / warning 橙 / danger 红 /
  info 天蓝）+ `__title` + `__subtitle` + `__actions`；垂直居中排版。

#### 4.5.11 回到顶部 `.yg-backtop`

- 右下角 40×40 圆角 md（G2）+ `--yg-shadow-md`，滚动出现淡入。

## 5. 高危操作规范

> **高危/破坏性操作 = 删除、清空、注销账号、退款、批量下架、不可逆提交等。**
> 高危操作唯一的识别色是红色 `--yg-color-danger #FF3B30`，红色不得用于其他场景。

### 5.1 触发样式

- 按钮：`.yg-btn--danger`（红底白字）；列表/表格行内操作用红色文字按钮
  （`.yg-btn--text` + `--yg-text-danger`）或红图标按钮。
- 不得在普通工具栏中放纯红实心按钮；多个操作并列时危险操作靠右（远离高频操作）。

### 5.2 必须二次确认

- 所有高危操作必须先弹出 `.yg-confirm` 确认框，包含：
  1. 红色警示图标 + 标题（动词句："删除该活动？"）；
  2. 描述后果："删除后所有报名记录将一并清除，且无法恢复。"；
  3. 按钮：取消（secondary，左）+ 确认（danger，右，动词"删除/清空/注销"）。
- 确认按钮点击后进入 loading，防止重复提交。
- 极高危操作（注销账号、清空全库）可要求输入对象名称或增加 3 秒冷静期。
- 成功后的反馈：`.yg-message--success` + 列表刷新；失败：`.yg-message--danger`。

### 5.3 危险状态反馈

- 表单校验错误、超限、失败提示可使用 `--yg-text-danger` 红字与红边框，
  但成功/信息类永远不用红。

## 6. 弹出层规范

> 弹出层 = 弹窗（modal）、抽屉（drawer）、气泡卡（popover）、文字提示（tooltip）、
> 下拉菜单（dropdown）、选择弹层（select）、全局消息（message）、通知（notification）。

### 6.1 面板铁律

1. **面板背景必须实色**：`background: var(--yg-bg-surface-raised)`（深色模式自动切换），
   **禁止**半透明背景、**禁止** `backdrop-filter`、禁止透明渐变底色。
2. **层次靠阴影**：面板一律 `--yg-shadow-lg`（最高层弹窗可 `--yg-shadow-xl`）。
3. **圆角**：弹窗/抽屉 xl（G2）；气泡/下拉 lg（G2）；tooltip/message md（G2）。
4. **动效**：300ms 内完成；弹窗缩放弹簧、抽屉位移、tooltip/下拉淡入上移。
5. **遮罩统一**：`.yg-mask`（`rgba(0,0,0,0.35)` + `blur(6px)`，毛玻璃渐变模糊），
   是弹出层体系中**唯一允许的半透明元素**。
6. **定位**：气泡类距触发元素 8px，自动翻转避让；消息顶部居中、通知右上角。
7. **层级**：popup 1050 / toast 1060 / tooltip 1070（`--yg-z-*` 令牌）。
8. **关闭**：遮罩点击、Esc、右上 × 均可关闭；modal 打开锁定滚动。
9. **无障碍**：`role="dialog"/"tooltip"` 等语义 + `aria-modal="true"`（modal）。

### 6.2 禁止清单（弹出层）

- ❌ `backdrop-filter` / `-webkit-backdrop-filter` 出现在任何弹出面板上。
- ❌ `background: rgba(...)` / `opacity < 1` 出现在弹出面板上。
- ❌ 使用 `.yg-frost`、`.yg-liquid-glass` 作为弹出面板背景。
- ✅ 唯一例外：`.yg-mask` 遮罩本身（属背景，非面板）。

## 7. CSS 架构与代码规范

### 7.1 文件组织

```
css/
├── main.css          总入口（@import，顺序固定）
├── design-tokens.css 设计令牌（唯一允许定义色值的文件）
├── base.css          Reset、排版、栅格、布局骨架、玻璃/G2 工具、遮罩
└── components/
    ├── buttons.css       基础交互
    ├── forms.css         数据录入
    ├── navigation.css    导航
    ├── data-display.css  数据展示
    └── feedback.css      反馈与弹层
```

- 新组件归入最相近的文件；跨文件复用用令牌而非相互依赖。
- 组件文件内禁用 `@import`（入口统一管理）。

### 7.2 命名

- 前缀 `yg-`；BEM 风格：`yg-block`、`yg-block__element`、`yg-block--modifier`。
- 状态一律 `.is-*`：`is-active / is-open / is-checked / is-disabled / is-loading /
  is-error / is-success / is-dragover / is-scrolled / is-selected / is-expanded`。
- 禁用 ID 选择器、禁用标签选择器深度覆盖（最多 3 层嵌套）。

### 7.3 写作规范

- 必须用 `--yg-*` 变量；颜色/圆角/阴影/间距/动效不得出现字面量。
- 禁止 `!important`（唯一例外：`prefers-reduced-motion` 降级块）。
- 注释全中文；每个文件头注释说明用途与范围；每个组件一个分节注释。
- 每个组件文件末尾提供：
  ```css
  @supports (corner-shape: squircle) {
    /* 本文件所有圆角组件的类名 { corner-shape: squircle; } */
  }
  ```
- 过渡属性写在常态规则上（`transition: ... var(--yg-dur-*) var(--yg-ease-*)`）。

- 开发预览：直接打开 `demo.html` 查看全部组件。

### 8.1 整站多构建（多份完整前端，不是多套配色/多套外壳）

主题清单是唯一事实源：`zvp5/themes/manifest.json`。示例（字段含义见文件内注释）：

| 主题 | 应用 | 部署路径 | 源码 | 设计特征 |
| --- | --- | --- | --- | --- |
| `canary`（default） | `zvp5/zvp5-frontend` | `/` | 本仓库 `v5-canary` | Phi：六边形底纹、速度线、判定线、棱角卡片、玻璃药丸导航 |
| `canary-pro` | `zvp5-frontend-pro` | `/themes/canary-pro/` | 清单 `source.ref` = `v5-canary-pro` | 工作台：固定左侧栏、面包屑顶栏、深色玻璃卡片 |
| `canary-anthropic` | `zvp5-frontend-canary` | `/themes/canary-anthropic/` | 清单 `source.ref` = `canary-anthropic` | 暖色工作台、圆角面板与自适应导航 |

约定：

1. **主题 = 独立应用**：每个主题有自己的 router、stores、views 与设计包，互不共享
   组件树。不要在本仓库 `src/` 里复制别分支的外壳组件、也不要用
   `html[data-theme-variant]` 收窄几行令牌假装成新主题。
2. **同源不同路径**：所有构建挂在同一域名下（`/` 与 `/themes/<id>/`），
   因此 `localStorage` 的 token 共享，切换主题 = 整页跳转，登录态无缝。
   非根主题的 `base` 必须是 `${prefix}${id}/`（构建器会校验）。
3. **构建入口只有 `zvp5/deployment/build-theme-apps.mjs`**：CI 在根 canary 构建之后
   读清单，用 `git worktree` 取出每个 `source`（`kind: "git"` 的 ref + path，
   或 `kind: "local"` 的仓库内路径），应用清单里的 `patch`、执行 `install` 与
   `command`（自动追加 `--base=<base>`），产物拷进
   `zvp5/zvp5-frontend/dist/themes/<id>/`，并生成运行清单 `dist/themes.json`。
   子应用的 `sw.js` / `workbox-*.js` 会被删除，避免 Service Worker 缓存干扰根应用。
4. **切换入口**：各应用在个人页或设置使用自己的样式，并给链接添加
   `data-zvms-theme-picker`。注入的 `/theme-switcher.js` 从 `/themes.json` 读取
   已部署主题，按版本展示可跳过的首次引导。选择后写入 `localStorage['zvms.theme']`，
   尝试 `PUT /v1/themes/me`，切换到另一主题时整页跳转。
5. **新增主题**：清单加一条 + 后端 `services/theme_registry.py` 加一条
   （`tests/test_theme_manifest.py` 会校验两边一致）。源码可以是另一条分支
   （`source: {kind:'git', ref, path}`），也可以将来把主题搬进本仓库
   （`source: {kind:'local', path}`）。不需要改 Worker / CI / 前端映射，
   也不需要复制外壳组件或改 `App.vue`。

## 9. 智能体执行清单

编写或修改义工平台前端时，逐项自检：

- [ ] 已通读本准则（重点：第 2、4、5、6、7 章）。
- [ ] 颜色/圆角/阴影/间距/动效全部引用 `--yg-*` 变量，无硬编码。
- [ ] 圆角取自 2.4 表格，并在组件文件内提供 `corner-shape: squircle` 渐进增强。
- [ ] 弹出层面板为实色 `--yg-bg-surface-raised`，未使用 backdrop-filter/半透明。
- [ ] 遮罩统一使用 `.yg-mask`；侧边栏玻璃用 `.yg-liquid-glass`。
- [ ] 未出现立体按钮、渐变浮雕、拟物装饰。
- [ ] 高危操作使用红色 + `.yg-confirm` 二次确认；红色未被滥用。
- [ ] 组件四态齐全（hover/active/focus-visible/disabled），弹出类含进出场动画。
- [ ] 类名 `yg-` 前缀 + BEM，状态用 `.is-*`；新组件已在第 4 章登记。
- [ ] 无 `!important`（reduced-motion 特例除外）；嵌套 ≤ 3 层。
- [ ] 响应式 ≤ 768px 验证；触控目标 ≥ 44px（移动端）。
- [ ] 键盘可达 + 焦点环可见；对比度 ≥ 4.5:1（正文）。
- [ ] 尊重 `prefers-reduced-motion`；暗色模式（`data-theme="dark"`）自测通过。
- [ ] 数字用 `.yg-text-num`；空态/加载态/错误态都有对应反馈。
