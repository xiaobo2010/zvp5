# 前端重构 v2 交付说明

> 目标：把义工平台前端整体换成「Apple 液态玻璃 + 瑞士国际主义」的界面语言。
> 约束：**只改前端**；路由与后端 API 一律不变（本文件末尾附 `git status` 证据）。

## 1. 设计系统（新增）

全部位于 `zvms4-modified-main/zvms4-frontend/src/assets/styles/v2/`：

| 文件 | 作用 |
| --- | --- |
| `tokens.css` | 颜色 / 玻璃 / 圆角 / 间距 / 动效 / 布局令牌，前缀 `--yg2-`，深色走 `[data-theme="dark"]` |
| `materials.css` | 光场（`.yg2-ambient`）、三层玻璃（`.yg2-glass`）、卡片（`.yg2-card`）、降级回退 |
| `typography.css` | 字阶（`.yg2-display` … `.yg2-mono`）与语义色 |
| `controls.css` | 按钮、字段、输入框、分段控件；键盘焦点环 |
| `patterns.css` | 页骨架（`.yg2-page`）、页头、面板、工具条、KV、徽标、空态 |
| `shell.css` | 应用壳（侧边栏 / 顶栏 / 移动底栏 / 抽屉） |
| `ep-bridge.css` | Element Plus 变量与组件的外观桥接（表格、分页、输入、按钮、弹窗、卡片） |

`src/main.ts` 的引入顺序：`tokens → materials → typography → controls → patterns → shell → ep-bridge`。
`base.css`（含全局 reset）**暂未引入**，避免影响未迁移页面。

## 2. 应用壳（新增）

`src/ui/shell/`：`AppSidebar.vue`、`AppTopbar.vue`、`AmbientField.vue`、`nav.ts`。
`src/App.vue` 的外壳模板整体替换为 `.yg2-app`（侧边栏 248px / 收起 76px、顶栏 64px、移动端抽屉 + 底部药丸导航），
登录页等公开路由走 `.is-plain` 纯内容布局。

- **活动详情** `components/activity/ZActivityPage.vue`、`ZActivityDetails.vue`（令牌迁移）
- **批量登记** `views/activity/VolunteerRegister.vue`（页头 + 卡片 + 工具条，业务逻辑未动）
- **创建义工** `views/activity/CreateActivity.vue`（页头 + 分段 tab）
- **个人资料** `views/user/UserProfile.vue`
- **他人主页** `views/user/UserPage.vue`
- **小组** `views/group/GroupPage.vue`
- **关于 / 404** `views/AboutView.vue`、`views/NotFound.vue`
- **管理域壳** `views/manage/ManageHome.vue`

管理域的角色 / 封禁 / 通知、服务器管理的数据库 / 动态码、AI 网关的额度 / OCR 等内页，
按 `.yg2-panel` + `ep-bridge.css` 统一皮肤兜底（不白屏、表格与表单是 v2 外观），内部排版未逐一重做。

## 4. 验收证据

- **类型检查**：`npm run type-check`（`vue-tsc --noEmit -p tsconfig.vitest.json --composite false`）
  稳定 `exit=2`、**32 条 `error TS`**，其中 4 条非 `DefaultRow` 的既存错误与本次改动无关；本轮未新增。
- **截图**：`yigong/.design-preview/` 下有 P0–P5 各阶段截图（浅色 / 暗色 / 390 移动端 / 减少动效）。
- **降级**：`prefers-reduced-motion: reduce` 下光场 `animation-name: none`；`prefers-reduced-transparency: reduce`
  下侧边栏回退实色、无 `backdrop-filter`。
- **对比度**：正文 `#1d1d1f`、次级 `#6e6e73`、三级 `#6f6f76` 对 `#f5f5f7` 均 ≥ 4.5:1；焦点环用实色 accent（≥3:1）。

## 5. 已知缺口

1. **真实数据未验收**：本地后端接口需要 401 鉴权，截图均用「假登录 + 阻断 API」或静态 demo 验证，
   列表/详情的真实数据排版（长标题、超长描述、多人列表）尚未在真实数据下过一遍。
2. 上述管理/服务器/AI 内页内部排版未做专门调整。
3. 三个待确认的设计判断：侧栏分组命名（概览 / 协作 / 管理）、移动底栏是否需要「创建」、表格行高密度。

## 6. 回滚

改动集中在 `src/` 与 `src/assets/styles/v2/`，未触碰 `src/router`、`src/api`、`zvms4-backend-python/`。
回滚方式：`git checkout -- zvms4-modified-main/zvms4-frontend/src` 删除新增的 `v2/`、`ui/shell/` 目录即可回到重构前状态。
