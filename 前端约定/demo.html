阅读说明
  • 悬停查看交互状态

    按钮、输入框、菜单等组件的 hover 状态请将鼠标悬停在元素上查看；键盘用户可用 Tab 聚焦查看焦点环（--yg-focus-ring）。

  • 弹出层面板一律不透明

    弹窗/抽屉/气泡/消息/通知面板均为实色 var(--yg-bg-surface-raised)，遮罩 .yg-mask 是唯一允许的半透明元素（见「弹出层」专节）。

  • 无外部依赖

    本页仅引用 css/main.css，图标全部为内联 SVG（线性、1.5px 描边），无任何 CDN、字体或图片依赖。

高危操作（准则第 5 章）

红色 --yg-color-danger 是破坏性操作唯一识别色，不得用于促销、装饰或普通提示；所有高危操作必须经 .yg-confirm 二次确认并说明后果与不可恢复性。

触发样式：危险按钮 / 描边 / 红字 / 红色图标
  • 滨江净滩行动

    行内高危操作：危险按钮靠右，远离高频操作

多个操作并列时危险操作靠右；点击下方「删除该活动」或上方红色「删除」均可打开 .yg-confirm 危险确认弹窗。

二次确认 · .yg-confirm（删除活动场景）
确认弹窗含：红色警示图标 + 动词句标题 + 后果说明 + 左取消右确认；确认后按钮进入 loading 防重复提交。

弹出层（准则第 6 章）

弹窗 / 抽屉 / 气泡 / 文字提示 / 下拉菜单 / 消息 / 通知。面板一律不透明（实色 var(--yg-bg-surface-raised)，禁止半透明与 backdrop-filter），遮罩 .yg-mask 是唯一允许的半透明元素；层级遵循 --yg-z-* 令牌；点击遮罩、Esc、右上 × 均可关闭。
