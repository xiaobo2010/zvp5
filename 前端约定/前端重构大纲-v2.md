# 义工平台 · 前端重构总纲 v2（Apple 液态玻璃方向）

> 状态：**设计大纲，待评审**。本文只定方向与布局，不含实现。
> 关系：取代 `前端设计准则.md` v1.0 中的视觉/布局部分；v1 的工程红线（禁 `!important`、禁硬编码色值、禁魔法数值、弹层实色、可访问性）继续有效。
> 范围：仅前端；路由、API、Pinia store、PWA 配置保持不变。

---

## 0. 一句话定位

**「清透的公共服务」**：内容是一块安静的哑光画布，导航与控件是浮在它上面的一层光学玻璃，光只从背景里透出来。

参考坐标不是 apple.com 的营销页，而是 Apple 自己的系统应用——设置、健康、钱包、健身——的克制与精确。营销级的大字与光影只出现在三个地方：登录、首页顶部、关于页。

---

## 1. 设计原则（五条，按优先级）

1. **内容是哑光的，玻璃只属于外壳。** 卡片、列表、表格一律实色；玻璃只出现在导航栏、悬浮控件、弹层这三层。内容层永远可读。
2. **一个强调色。** 全站只允许一种强调色 + 一种数据暖色（志愿时长）。其余全部交给灰阶和字重。
3. **层次靠光，不靠边框。** 用投影、内高光、背景明度差表达层级；1px 边只做结构线，不做装饰。
4. **动效回答动作，不表演。** 打开/关闭/切换必须有反馈；进入页面不做逐块飞入，只做一次轻的整页过渡。
5. **呼吸感即高级感。** 桌面端内容最大宽 1160，行高 1.5–1.6，段落间距 ≥ 24，留白优先于信息密度。

## 2. 视觉语言

### 2.1 色彩

| 角色 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| 页面底 | `#F5F5F7` | `#000000` | 画布 |
| 内容面 | `#FFFFFF` | `#1C1C1E` | 卡片、列表、表格 |
| 下沉面 | `#EDEDF0` | `#2C2C2E` | 输入框底、代码块、分组底 |
| 主文字 | `#1D1D1F` | `#F5F5F7` | 标题、正文 |
| 次文字 | `#6E6E73` | `#98989D` | 说明、元信息 |
| 弱文字 | `#86868B` | `#8E8E93` | 占位、禁用 |
| 结构线 | `rgba(0,0,0,.08)` | `rgba(255,255,255,.10)` | 1px 分隔 |
| 强调色 | `#0071E3` | `#0A84FF` | 主按钮、链接、选中态 |
| 强调浅底 | `rgba(0,113,227,.10)` | `rgba(10,132,255,.16)` | 选中行、聚焦底 |
| 数据暖色 | `#FF9F0A` | `#FF9F0A` | **仅**志愿时长/贡献数据 |
| 成功 | `#34C759` | `#30D158` | 完成、通过 |
| 警告 | `#FF9F0A` | `#FF9F0A` | 待处理 |
| 危险 | `#FF3B30` | `#FF453A` | 高危操作，必须二次确认 |

**环境光（签名元素）**：页面背后固定一层极低饱和的渐变光场，随板块换色相（`--ambient-hue`）：

- 浅色：三团 8–14% 透明度的径向渐变（冷蓝 `#C9E3FF`、暖沙 `#FFE3C2`、淡紫 `#E9E6FF`），位置 60–80 秒极慢漂移；`prefers-reduced-motion` 时静止。
- 深色：同结构，透明度 25–35%，叠在纯黑上，形成"光从玻璃后面透出来"的观感。
- 光场只做背景，**永不给它加 blur 动画**；用两三个固定 div + CSS animation，不用 canvas/WebGL。

### 2.2 字体

```css
--font-sans: -apple-system, BlinkMacSystemFont, "SF Pro Text", "SF Pro Display",
             "PingFang SC", "Hiragino Sans GB", "Noto Sans SC", "Helvetica Neue", Arial, sans-serif;
--font-mono: "SF Mono", ui-monospace, "JetBrains Mono", Menlo, monospace; /* 仅日志/代码 */
```

- **不引入 Web 字体**。系统字体栈在 macOS/iOS 即 SF + 苹方，Windows 回落到 Noto/微软雅黑，零加载成本、零 FOIT。
- 数字统一 `font-variant-numeric: tabular-nums`（时长、人数、ID、金额）。
- 中文正文 16px / 行高 1.65；英文正文 17px / 1.5。

|---|---|---|---|---|
| Display | 56/60 | 600 | -0.035em | 登录、关于页主视觉（仅此两处） |
| H1 | 34/40 | 600 | -0.02em | 页面标题 |
| H2 | 28/34 | 600 | -0.02em | 区块标题 |
| H3 | 22/28 | 600 | -0.01em | 卡片标题 |
| Headline | 17/22 | 600 | -0.01em | 列表主行、按钮 |
| Body | 16/26 | 400 | -0.005em | 正文 |
| Callout | 15/21 | 400 | 0 | 辅助说明 |

### 2.3 圆角 · 同心圆角

`--radius-8 / 12 / 16 / 20 / 26 / 32 / pill`

- 卡片 20，面板/弹层 26，Sheet 顶部 32，控件 12，列表行 16，头像/胶囊 pill。
- **同心规则**：子元素圆角 = 父圆角 − 内边距（例：卡片 20、内边距 4 → 子块 16）。
- `@supports (corner-shape: squircle)` 时对卡片与按钮启用连续曲率；圆形元素不套。

### 2.4 材质（三层玻璃 + 一层哑光）

| 层 | 令牌 | 模糊 | 填充（浅/深） | 用于 |
|---|---|---|---|---|
| Chrome | `--mat-chrome` | 28px / saturate 180% | `rgba(255,255,255,.55)` / `rgba(30,30,32,.55)` | 侧边栏、顶栏、底部导航 |
| Control | `--mat-control` | 20px | `.65` / `.6` | 分段控件、胶囊按钮、悬浮操作条 |
| Overlay | `--mat-overlay` | 32px | `.78` / `.72` | Sheet、Popover、Toast、命令面板 |
| Surface | `--surface` | — | 实色 | 卡片、列表、表格、表单 |

玻璃配方（Chrome 示例）：

```css
background: var(--glass-fill);
backdrop-filter: blur(28px) saturate(180%);
border: 1px solid var(--glass-stroke);
box-shadow:
  inset 0 1px 0 var(--glass-highlight),   /* 顶边高光：模拟折射 */
  inset 0 -1px 0 rgba(0,0,0,.04),         /* 底边暗线 */
  0 1px 0 rgba(0,0,0,.03);
```

玻璃铁律：

1. **玻璃不叠玻璃**：同屏最多两层可见玻璃，且不得嵌套。
2. **玻璃不盖正文**：玻璃层内只放导航、图标、短标签；正文不得压在玻璃上。
3. **玻璃不吃滚动内容**：`backdrop-filter` 只给 `position: fixed/sticky` 的窄条；滚动容器本身绝不加 blur。
4. **降级**：`@supports not (backdrop-filter: blur(1px))` 与 `@media (prefers-reduced-transparency: reduce)` 一律回落实色 + 1px 边。
5. **性能预算**：同屏 blur 层 ≤ 3；移动端模糊半径降为 18–20px；`contain: paint` 加在卡片上。

### 2.5 阴影

```css
--shadow-ambient: 0 1px 2px rgba(0,0,0,.04), 0 8px 24px -12px rgba(0,0,0,.10);
--shadow-raised:  0 2px 6px rgba(0,0,0,.05), 0 20px 48px -24px rgba(0,0,0,.18);
--shadow-float:   0 12px 40px -8px rgba(0,0,0,.18), 0 2px 8px rgba(0,0,0,.06);
```

深色模式阴影改为黑色加深 + 顶边 1px 高光补偿，避免卡片"糊"在黑底里。

### 2.6 间距与栅格

- 4pt 基准：`4 8 12 16 20 24 32 40 48 64 80 96`
- 桌面：12 栏、24px 槽、内容最大宽 **1160**、页面左右 40
- 平板：8 栏、20px 槽、左右 32
- 手机：4 栏、16px 槽、左右 16
- 卡片内边距：20（小）/ 24（标准）/ 32（主视觉卡）
- 区块间距：40；页面头部到内容 32

### 2.7 图标

- 1.5px 线性，20/24 两档，圆角端点。
- 优先用仓库 `SFSymbols/` 里的符号转 SVG（保持 Apple 观感）；新增图标统一 24 网格、1.5 描边。
- 禁止 emoji 当图标。

### 2.8 动效

```css
--dur-1: 120ms;  --dur-2: 220ms;  --dur-3: 360ms;  --dur-4: 560ms;
--ease-out: cubic-bezier(.22,1,.36,1);
--ease-in-out: cubic-bezier(.4,0,.2,1);
```

- 按压：`transform: scale(.97)` 100ms（仅控件，不用于整卡）。
- 进入：透明度 0→1 + 位移 8px，220ms；退出 160ms（退出快于进入）。
- 列表入场最多 6 项、间隔 30ms，超出直接显示。
- 页面切换：`document.startViewTransition` 可用时 220ms 交叉淡化 + 0.995→1 缩放；不可用时直接切换。
- 侧栏收起/展开：360ms，宽度只做裁剪不做重排（`transform` + `clip-path` 或 grid 过渡）。
- `prefers-reduced-motion: reduce`：去掉位移与缩放，只保留透明度。

## 5. 组件体系

**基础（自建，`src/ui/`）**：Button、IconButton、Segmented、Tabs、Input、Textarea、Select、SearchField、Switch、Checkbox、Radio、Tooltip、Popover、Sheet、Dialog、Toast、Menu、Avatar、Badge、Chip、ProgressRing、Skeleton、EmptyState、SectionHeader、InsetList/ListRow、Stat、Table、Pagination、Banner、PassCard。

**布局**：AppShell、Sidebar、TopBar、PageHeader、ContentGrid、Bento、RightRail、StickyActionBar。

**业务（沿用现有视图，重排版）**：活动卡/列表/详情、报名表单、成员列表、权限矩阵、服务器卡片、日志表。

**Element Plus 策略（建议）**：复杂控件（日期时间选择、上传、表格排序、表单校验）保留 EP，只做令牌级重绘；导航、按钮、卡片、弹层、列表全部自建。理由：全量替换 EP 风险高、工期长；只换皮又保留不了 Apple 观感。

**四态**：hover / active / focus-visible / disabled 必须齐备；focus 环 3px 强调色 40%，仅在键盘导航出现。

## 6. 可访问性与质量底线

- 正文对比度 ≥ 4.5:1，控件 ≥ 3:1；玻璃上的文字必须实测（用深色底最坏情况）。
- 触控目标 ≥ 44×44；手机底部导航项 ≥ 48 高。
- 全键盘可达；Sheet/Dialog 焦点陷阱与 Esc 关闭；跳过导航链接。
- `prefers-reduced-motion` / `prefers-reduced-transparency` 全覆盖。
- 200% 缩放不横向滚动；`rem` 为主，容器查询用于卡片内部。
- 图片 AVIF/WebP + 宽高预留（CLS < 0.1）；大表格虚拟滚动（>100 行）。
- 暗色模式不是反色：深色下提升边框与高光，降低大面积纯白。

### 7.2 分阶段

### 已知注意事项

- `flat.css` 把 EP 的 `.el-button--primary` 变量绑到 v1 令牌 `--yg-color-primary`，而 v1 令牌随 `.yg-layout` 一起移除后，主按钮会退化成「白底白字」；`ep-bridge.css` 里已用 `.el-button.el-button--primary` 重新绑定 v2 令牌，新增页面不要覆盖这组变量。
- `.yg2-card` 不带内边距，页面需自带 padding。
- `.yg2-panel` 用于包裹「直出」的遗留列表组件，并会压平其内部 `ElCard`。
- 页面内不要再局部覆盖 `--el-color-primary: var(--yg-color-primary)`（v1 令牌），否则 EP 主按钮会失去颜色；统一由 `ep-bridge.css` 提供。
- `.yg2-toolbar` 是列表工具条：`__grow` 占满剩余宽度、`__field` 固定 160px、`__end` 右对齐。
- 减少动效的覆盖规则必须比 `.yg2-ambient__blob:nth-child(n)` 更具体，现用 `.yg2-ambient .yg2-ambient__blob`（已验证：reduce 下 animation-name = none）。
- `--yg2-text-tertiary` 浅色由 `#86868b` 调深到 `#6f6f76`（对 `#f5f5f7` 3.33:1 → 4.58:1，达到 AA 正文级）。
- EP 的危险按钮（`.el-button--danger`）改为「浅底红字」，实心红只留给 `.yg2-btn--danger` 的高危确认场景。
- 键盘焦点环由 `controls.css` 里 `html a/button/[role=button]/.el-button:focus-visible` 用 3px 实色 accent outline 承担（v1 的 `yg/base.css` 用 box-shadow 画天蓝环，两套环会叠加，必须显式 `box-shadow: none`）。
- v2 的 `base.css` **尚未引入**（含全局 reset），全局焦点规则因此放在 `controls.css`。
